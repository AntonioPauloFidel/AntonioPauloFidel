# Olá, sou o Antonio 👋

Dev full-stack em Palmas (TO). Comecei no suporte de TI, passei pela infraestrutura e hoje trabalho no sistema inteiro: API, front web e mobile, banco de dados, Docker, CI/CD e o servidor onde tudo roda.

Hoje estou no **SENAI-TO** (TI e Inovação) e atendo como freelancer pela **MR Info**. Antes, passei 1 ano e meio na **Mix Alimentos**, onde entrei como estagiário de infraestrutura e saí como dev full-stack. Curso Engenharia de Software na ULBRA Palmas.

**Aberto a oportunidades.**

## O que estou construindo

- **[IGNIS](https://github.com/saviodev0/IGNIS_Back_end):** app de estudos com Pomodoro e um assistente de IA que lê os PDFs do aluno e responde citando a página. NestJS, Prisma, React Native, busca semântica com embeddings e OCR.
- **Culture OS:** plataforma de RH com 9-Box, OKRs e avaliação 360°, feita com a equipe BitStudioLabs. Sou o principal contribuidor, com mais de 250 commits. FastAPI, React e um assistente de IA local com Ollama e pgvector. *(repositório privado)*
- **[TankScript](https://github.com/AntonioPauloFidel/Domain-Specific-Language):** linguagem de programação própria, com parser em ANTLR, análise semântica e interpretador, que controla um jogo de estratégia com interface em Phaser.

## Destaques

- **MR Info:** integrei a emissão de NF-e às regras da Reforma Tributária, corrigi uma falha de acesso a arquivos sem autenticação e criei uma fila de requisições para o acesso a vídeos da plataforma.
- **Mix Alimentos:** monitorei a infraestrutura com Zabbix e Grafana, configurei Nginx, Apache, firewall e ambientes de homologação e produção, e depois desenvolvi módulos do portal corporativo em Django + React com CI/CD no GitHub Actions.
- **SENAI-TO:** suporte a unidades em todo o Tocantins e extração de dados para relatórios gerenciais.
